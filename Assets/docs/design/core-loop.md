# Tiny Fishing Core Loop

## Tiny Fishing의 핵심 루프

**낚싯대 조준 → 캐스팅 → 입질 대기 → 타이밍에 맞춰 후킹 → 물고기 방향에 맞춰 릴링 → 포획 및 점수 획득 → 다시 캐스팅**

### 1. 조준 및 캐스팅

플레이어는 스마트폰을 기울이거나 화면을 드래그해 낚싯대의 방향을 조절한다. 자이로 모드에서는 기기를 흔드는 강도, 터치 모드에서는 드래그 동작에 따라 캐스팅이 실행된다.

### 2. 입질 대기

찌가 물에 도착하면 물고기가 미끼에 접근할 때까지 기다린다. 물고기가 도착하면 찌가 가라앉으며 짧은 후킹 기회가 주어진다.

### 3. 후킹

플레이어는 입질 타이밍에 화면을 터치해 물고기를 낚아챈다. 너무 일찍 조작하거나 제한 시간 안에 반응하지 못하면 물고기를 놓친다.

### 4. 릴링

물고기가 움직이는 방향에 맞춰 낚싯대 방향을 조절하고 반복해서 터치한다. 방향이 일치하면 포획 진행도가 증가하고, 일치하지 않으면 진행도가 감소한다.

### 5. 결과 및 반복

진행도를 모두 채우면 물고기를 포획하고 종류와 희귀도에 따른 점수를 획득한다. 실패하거나 포획이 끝나면 다시 캐스팅 단계로 돌아간다.

## 3분 타임어택 루프

타임어택 모드에서는 위의 낚시 과정을 3분 동안 최대한 빠르게 반복한다. 제한 시간이 종료되면 누적 점수와 잡은 물고기 수를 기준으로 최종 결과를 표시한다.

## 핵심 재미

- 실제 낚싯대를 다루는 듯한 자이로·터치 조작
- 입질 순간에 반응하는 짧고 명확한 타이밍 플레이
- 물고기 움직임을 따라가는 방향 조절과 반복 터치의 긴장감
- 제한 시간 안에 더 높은 점수를 노리는 빠른 재도전 구조
