# Overview
무한모드와 시간제한모드가 공유하는 낚시의 기본 방법에 대한 개발 방향을 기술한다.
design/core-loop.md에 기술된 4가지 게임흐름에 대한 구현방법을 기술함.

### 1. 조준 및 캐스팅

fishing_input에서 추상화된 좌우 value와 Event를 활용해 처리한다.

### 2. 입질 대기

캐스팅이 완료된 이후, 랜덤으로 특정 범위의 수치를 만들어 낸 이후, 그 시간에 맞게 물고기가 찌에 도달하도록 애니메이션을 조정한다.

### 3. 후킹

2에서 설정한 시간이 지나고, 물고기가 도달하면, 0.3~0.5초 내외의 시간동안 후킹 기회를 부여한다.
그 기간동안 입력 시스템의 event가 없으면 실패로 간주한다.

### 4. 릴링

물고기의 speed, frequency를 참고하여 움직임을 시뮬레이선하고, 입력 시스템의 좌우 value와 비교해 특정 수치 아래이면 릴링을 성공으로 판정한다.
성곧했을 시 상하 value를 참고하여 추가 릴링 퍼센트를 부여한다.

### 5. 결과 및 반복

진행도를 모두 채우면 물고기를 포획하고 종류와 희귀도에 따른 점수를 획득한다. 실패하거나 포획이 끝나면 다시 캐스팅 단계로 돌아간다.
