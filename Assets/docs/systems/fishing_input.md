# Input System

## 개요 및 원칙
낚시 과정 중 플레이어의 입력을 처리하기 위한 Input System 구축 내용을 기술한다.
Unity Input System을 사용하고, 자이로 기반 입력과 터치 기반 입력을 처리, 추상화하여 다른 시스템에서 활용할 수 있게 한다. 

## 목표
- 자이로, 터치 입력들을 추상화 하여 다음과 같은 값으로 만들어 내야한다.
    - 낚시대 좌우 기울이기, 낚시대 상하 높이 조절, 낚시대 후킹, 낚시대 릴링, 낚시대 스윙(던지기)
- 2가지 입력 방식(자이로, 터치)를 지원하며 둘의 결과물은 같아야한다.
- 2가지 입력 방식을 설정할 수 있는 api가 제공되어야한다.
- 방식별로 입력 민갑도를 조절할 수 있는 api가 제공되어야한다.
- 각 입력은 Event 혹은 값을 읽을 수 있는 public state로 제공한다.

## 자이로 입력
원점을 재조정할 수 있는 api를 제공해야한다.(Recalibration)
### 낚시대 좌우 기울이기(Value)
- 휴대폰 좌우 틸트(Roll)를 낚시대 기울이기로 인식한다
- Math.Clamp를 통해 좌우 최대치를 조절한다.

### 낚시대 상하 조절(Value)
- 휴대폰을 상하로 기울이는 값을 인식한다.(Pitch)
- Math.Clamp를 통해 좌우 최대치를 조절한다.

### 낚시대 후킹, 릴링(Event)
- 화면 터치 입력을 후킹으로 인식한다.
- 게임의 단계 별로, 같은 입력을 후킹, 릴링으로 취급하지만, 해당 판단은 이 시스템의 책임범위가 아니므로, 터치를 했는지 여부를 확인할 수 있는 Event를 제공한다.

### 낚시대 스윙(Event)
- 휴대폰을 상하로 기울이는 속도을 인식한다.(Pitch)
- 특정 값이상 빨리 움직인 경우 Event를 발생시킨다.
